# 小世界的创世神

Andy Yu 的自传，做成了一本可以翻页的魔法书：左右各一页，每章配一幅会动的插图。

## 打开方式

直接用浏览器打开 `index.html` 即可，不需要安装任何东西。

- 点右页往后翻，点左页往回翻
- 键盘 ← → 也可以翻页，Home / End 跳到封面 / 封底
- 手机上自动变成单页，左右滑动翻页
- 底部「目录」按钮可以跳到目录页，目录里的章节都能点
- 同一份内容有两条读法，扉页上或底栏按钮可以切换：
  - **时间线篇**：按发生的顺序，从琴键一路读到 X岛
  - **项目篇**：五个项目（敦煌、BIA、Cognitive Echoes / ACPF、小满、X岛），每章先讲一段成长经历，再接一段过渡，最后链接到作品集网站上对应的项目页
- 网址末尾加 `#time` 或 `#projects` 可以直接打开某一篇

## 结构

全部内容在一个文件 `index.html` 里：

- 正文段落都在脚本里的内容库 `B` 里，每段有一个名字（比如 `fall`、`detector`）
- 每一篇是 `ED` 里的一份章节清单，章节用名字引用段落，所以同一段可以出现在不同的篇里
- 清单里可以插入 `{div: '那时的我'}`（小标题）、`{note: '...'}`（手写批注），段落里的 `{plate: ...}` 会生成一整页插图，`{link: ...}` 会生成通往作品集的链接卡片
- 插图是代码画的 SVG 动画，定义在 `F` 对象里
- 排版是在浏览器里实时分页的，换窗口大小会重新排

字体来自 Google Fonts（马善政、Noto Serif SC、IM Fell English、龙藏）。
